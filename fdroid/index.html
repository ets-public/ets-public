Enhanced Training Studio on F-Droid

Enhanced Training Studio from its developer: the same app as on https://enhancedtraining.app. Add this repository to the F-Droid app once, and updates arrive there like any other app. Tracking your protocol is free; training, blood tests and health unlock with a licence key.

Add to F-Droid

Open this page on your phone with F-Droid installed. If the button does nothing:

  1. In F-Droid, open Settings → Repositories and tap +.
  2. Enter this address: __URL__?fingerprint=__FP__
  3. Check the fingerprint F-Droid shows matches the one below, then add it.

Repository fingerprint (SHA-256)

__FP__

The app is signed with the same key as the downloads on https://enhancedtraining.app and GitHub, so F-Droid can update an app you installed from there, keeping your data.

Have a licence?

Enter your key in the app (Setup → App settings → Licence) and training, blood tests and health unlock. Nothing else to install.

The free edition's source code is at https://github.com/ets-public/ets-public. The parts that need a licence aren't open source, so this build isn't made from that code alone.
